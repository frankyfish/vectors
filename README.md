### Vectorizer

Configured per collection. Use a Weaviate vectorizer integration — Configure a vectorizer for a collection, and Weaviate automatically generates vectors on import and at query time.
Bring your own vector (BYOV) — Upload pre-computed vectors directly. If doing this, set the vectorizer to none to avoid accidentally generating incompatible vectors.
